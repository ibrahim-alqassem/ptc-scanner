# ماسح توافق الزمن والسعر

يطبّق منطق مؤشري **توافق الزمن والسعر (PTC)** و**صائد الاختراقات (BH)** على السوقين الأمريكي والسعودي، وينشر النتائج على صفحة GitHub Pages.

- يعمل تلقائياً بعد إغلاق السوق السعودي (الأحد–الخميس) وبعد إغلاق السوق الأمريكي (الاثنين–الجمعة).
- للتشغيل يدوياً: Actions ← scan ← Run workflow.
- قائمة المراقبة: `watchlist.txt` (رمز في كل سطر، والسعودي ينتهي بـ `.SR`).
- رموز السوق السعودي: `saudi.txt`.

أداة مساعدة وليست توصية استثمارية.
